# MAD Practical 7 – Alarm App ⏰

## 📱 About the Project

This project is developed as **Practical 7 for Mobile Application Development (MAD)**.

The application is an **Alarm App** developed using Android Studio. It allows users to set an alarm for a selected time and manage the alarm through a simple and user-friendly interface.

## 🎯 Objectives

* To understand Android application development.
* To implement alarm functionality in Android.
* To work with time and date selection.
* To start and stop an alarm.
* To understand Android services and alarm-related components.
* To design a simple and interactive Android user interface.

## ✨ Features

* ⏰ Set an alarm
* ▶️ Start the alarm
* ⏹️ Stop the alarm
* 🕐 Select the required time
* 📱 Simple and user-friendly interface
* 🔔 Alarm notification/ringing functionality

## 🛠️ Technologies Used

* **Android Studio**
* **Kotlin / Java**
* **Android SDK**
* **Gradle**
* **XML** for UI Design

## 🚀 How to Run the Project

1. Clone the repository:

```bash
git clone https://github.com/saipatil29/24012011148_mad_pr7.git
```

2. Open **Android Studio**.

3. Select **Open** and choose the downloaded project folder.

4. Allow Android Studio to sync the Gradle files.

5. Connect an Android device or start an Android Emulator.

6. Click the **Run ▶️** button.

7. Use the application to set, start, and stop an alarm.
